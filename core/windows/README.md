# Xray-core Binary

Place the Xray-core executable file here.

## How to get Xray-core

1. Download the latest release from: https://github.com/XTLS/Xray-core/releases
2. Choose the Windows version (e.g., `Xray-windows-64.zip`)
3. Extract the archive
4. Copy `xray.exe` to this directory

## Supported versions

- Windows 64-bit: `xray.exe`

## Verification

After placing the file, the application will verify its existence on startup.
