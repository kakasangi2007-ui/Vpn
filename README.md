# VPN Client

A professional VPN client built with Python and Flet, powered by Xray-core.

## Features

- 🚀 **Multiple Protocols**: Supports VLESS, Trojan, VMess, and Shadowsocks
- 📊 **Real-time Statistics**: Live traffic monitoring and charts
- 🌓 **Dark/Light Theme**: Choose your preferred appearance
- 📱 **Cross-Platform**: Windows, Linux, macOS (Android support planned)
- 🔄 **Auto-Connect**: Connect automatically on start
- 📜 **Connection History**: Track your connection history
- ⚡ **Fast & Lightweight**: Built with Flet for modern UI
